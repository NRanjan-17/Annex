## Annex 0.2.0-pre.5

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. Thanks to [@SkidGod4444](https://github.com/SkidGod4444). Everything in pre.1 to pre.4 is included.

### Changed since pre.4

- **Direct Wi-Fi uses your PC's own Mobile hotspot**, exactly as it's set up in Windows Settings → Network & internet → Mobile hotspot. Annex no longer makes up a new network name and password each time, so the other computer remembers the network and joins faster, and your hotspot settings are never changed. A hotspot you'd already turned on stays on afterwards.
- **The PIN box shows six asterisks** instead of a sample PIN.

### Fixed since pre.4

- **Mac: Extend stopped working after choosing Mirror in System Settings.** macOS remembers Mirror for the Annex display, and a mirrored display has no picture of its own, so every later Extend from that PC ended at once. The other computer now shows the Mac's screen as a mirror; choose *Extended display* in System Settings → Displays to extend again.
- **Windows: "Can't find it?"** on Nearby is as wide as the panel above it.
- A network test that failed now and then on Windows is steady.
