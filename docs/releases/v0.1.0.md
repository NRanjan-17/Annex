## Annex 0.1.0

The first release. Annex shows one computer's screen on another over your local network: a Mac and a Windows PC, in either direction. No account, no cloud and no relay server are involved.

### What it does

- **Mirror:** see another computer's screen in a window.
- **Extend:** use the other computer as an extra display. On Windows this needs the optional Extend-mode display driver from the installer.
- **Control:** use the shared computer's mouse and keyboard. The sharing side asks first, and you can change it later in Paired Devices. Press Ctrl+Alt+Shift+Q (⌃⌥⇧Q on a Mac) to leave a session.
- **Pairing:** the first connection needs a 6-digit PIN. After that, paired devices connect straight away. Connections are encrypted, and each device checks the other's identity.
- **Nearby:** every open Annex on the network is listed, whether it's sharing or not.
- **Quality:** choose Best, Balanced or Fast. Annex lowers the bit rate when the network gets slow.
- **Wi-Fi:** Windows turns on its low-latency Wi-Fi mode during a session. A Windows PC can also start its own hotspot so a Mac connects to it directly.
- **Graphics:** uses the hardware video encoder where available. On PCs with more than one graphics card, you can choose which one shares.
- **Log file:** off by default. Turn on "Save a log file" in About when reporting a problem.

### Before you install

- **macOS:** this build is not notarized. Right-click Annex and choose Open the first time. Grant Screen Recording again after each update.
- **Windows:** the installer is unsigned, so SmartScreen may warn you. The Extend driver is signed on your PC during setup. Smart App Control can block that step; if Extend says the driver isn't ready, reinstall with the driver option ticked.

### Known issues

- After a device stops sharing, the other device sometimes doesn't list it again until Annex restarts. This build asks the network again more often, which should fix it.
- The direct Wi-Fi link works only with the Windows PC as the hotspot. Mac to Mac direct links aren't supported yet.
