## Annex 0.4.2

Computers with **No one at this screen** on now update themselves, and scrolling works again on Linux with GNOME. **Install this one by hand on each computer;** from here on, unattended computers keep up on their own.

### New

- **Unattended computers update themselves.** With **No one at this screen** on (and **Check for updates** on), Annex downloads a new version as soon as it's out, checks its signature, and installs it once no one has been connected for a minute. It comes back sharing, as before. If the new version doesn't start within 90 seconds, Annex puts the old one back and won't try that version again on its own. Computers with someone at the screen still ask first.
  - **Mac:** replaces Annex in its folder.
  - **Windows:** installs for the current user; an all-users install still asks.
  - **Linux:** a .tar.gz install updates in its own folder; a .deb or .rpm install updates through a small helper installed with Annex, so no password is needed.

### Fixed

- **Scrolling on Linux with GNOME.** Scrolling from the viewer did nothing on GNOME (Wayland): GNOME dropped each scroll step. Annex now sends them the way GNOME expects, so the wheel and trackpad scroll again.
