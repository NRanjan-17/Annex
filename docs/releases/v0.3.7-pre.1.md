## Annex 0.3.7-pre.1

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. **Install it on both computers.** Thanks to [Saidev Dhal](https://saidev.codes) for the logs that found this.

### Improved

- **More internet connections go direct, without the relay.** Some internet providers share one public address among many homes, and their routers give each connection its own port. A viewer used to knock on the wrong port, give up and use the relay. Annex now also connects to the port that computer's router really uses. Nothing new is opened to anyone: it's a path the sharing computer's own router made towards the viewer, and only packets signed with your code can point Annex to it.
- **The log says why a connection used the relay.** It names the network that blocked a direct connection (this one, the other one, or both), and notes when a session connects directly or switches to the relay.

### Still the same

Every session is end to end encrypted (TLS 1.3, checked against each computer's identity), whether it's direct or through the relay. The relay only forwards packets it can't read.
