## Annex 0.1.4

### New

- **Settings in one place.** One Settings page with clear sections: General, Sharing, Viewing, Paired devices, Updates, Developer and About. On a Mac, ⌘, opens it.
- **Less technical clutter.** Identity codes, addresses, stream sizes and latency figures are hidden. Turn on **Settings → Developer → Show technical details** to see them. The log file switch moved to Developer too.
- **A new app icon.**

### Fixed

- **Windows: no more crash when clicking while controlling the other computer.** Clicking in the viewer window while using your mouse and keyboard on the other computer could close Annex.
- **Windows: one "Connected now" list** on the Share page, with *Switch to direct Wi-Fi* for each viewer.
