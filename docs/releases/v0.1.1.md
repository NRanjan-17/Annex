## Annex 0.1.1

### New

- **Updates inside Annex.** Settings → General → Updates. Annex checks GitHub at launch and once a day and installs new versions for you. **Beta updates** gets pre-releases early; turn it off to go back to the latest normal release. Every update is checked against a signature made when the release is built, so a modified download is never installed.
- **Signed and notarized on Mac.** Annex opens without the "unidentified developer" warning, and macOS keeps its permissions across updates. (You grant Screen Recording one last time after moving to this version.)
- **Direct Wi-Fi, before or during a session.** Turn on *Connect over direct Wi-Fi* to move each session onto the PC's hotspot right after it connects, or switch a running session from either computer. On Windows, *Share this PC → Direct Wi-Fi* runs the hotspot and shows its name and password.
- **Refresh Nearby.** A refresh button next to Nearby re-checks the list.
- **A cleaner Mac disk image.** Just Annex and Applications. The uninstaller is now in Annex: **About → Uninstall…**.

### Fixed

- Extend on Windows: the display driver no longer crashes or rejects the extra display, and the new display is found and turned on reliably.
- A computer that stopped and started sharing no longer disappears from Nearby.
- After switching to direct Wi-Fi, the viewer reconnects as soon as the other computer joins the hotspot.
- A closed viewer can no longer end the session that replaced it.
- The Mac no longer stays extended onto a black display when capture fails.
- Each graphics card is listed once in the Windows picker.
- If Windows' Smart App Control blocks Annex, it says so.
- Updated a dependency for a security advisory (RUSTSEC-2026-0385).

### Known issues

- The Windows installer isn't code-signed yet, so SmartScreen or Smart App Control may warn about it.
- The direct Wi-Fi link needs the Windows PC to run the hotspot; two Macs can't use it.
