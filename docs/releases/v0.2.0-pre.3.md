## Annex 0.2.0-pre.3

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. Thanks to [@SkidGod4444](https://github.com/SkidGod4444). Everything in [0.2.0-pre.1](https://github.com/NRanjan-17/Annex/releases/tag/v0.2.0-pre.1) and [pre.2](https://github.com/NRanjan-17/Annex/releases/tag/v0.2.0-pre.2) is included.

### Fixed since pre.2

- **A pre-release installed by hand was offered 0.1.9 as an update.** Until you change the Beta updates switch, Annex now follows what's installed: a pre-release gets newer pre-releases. The daily check never offers going back to an older version; only turning Beta updates off, or Check now, does.
- **Turning Beta updates on or off during a check** now takes effect: Annex checks again when the running check ends.
- **The old update offer** now disappears as soon as you change the switch.
