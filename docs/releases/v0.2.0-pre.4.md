## Annex 0.2.0-pre.4

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. Thanks to [Saidev Dhal](https://saidev.codes). Everything in pre.1 to pre.3 is included.

### Fixed since pre.3

- **Mac: the switches in a computer's card line up** on the right, however long their titles are.
- **Mac: the viewing Mac closes Annex's window as soon as a session ends**, instead of after a short pause.
- **Windows: Extend can be read when it's not available.** A button that can't be used now fades as a whole instead of turning its text grey, which disappeared on the white Extend button.
- **Windows: Quit Annex in the tray menu** is now a small button you can see, like View next to each computer.
- **Windows: the small spinners can be seen** against the black background.
