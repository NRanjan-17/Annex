## Annex 0.3.0

Thanks to [Saidev Dhal](https://saidev.codes) for most of this release. **Install it on both computers.**

### New

- **Annex for Linux.** Share a Linux screen, view other computers, and use a Linux computer as an extra display (Extend), with the same pairing and encryption as the Mac and Windows apps. Packages for x86_64 and arm64: `.deb` (Ubuntu, Debian, Raspberry Pi OS), `.rpm` (Fedora, openSUSE) and `.tar.gz`. Tested on a Raspberry Pi 5. See [docs/LINUX.md](https://github.com/NRanjan-17/Annex/blob/main/docs/LINUX.md).
- **Headless mode: control a computer no one is sitting at.** Turn on **No one at this screen** (Mac and Windows) or run `annex --headless` (Linux). The pairing PIN is also written to `pairing-pin.txt` in Annex's data folder, so you can read it over SSH, and paired devices can control the computer without someone clicking Allow. The file is readable only by you and is deleted once pairing ends.
- **One-line install on every system.** Mac and Linux: `curl -fsSL https://raw.githubusercontent.com/NRanjan-17/Annex/main/scripts/install.sh | sh`. Windows (PowerShell): `irm https://raw.githubusercontent.com/NRanjan-17/Annex/main/scripts/install.ps1 | iex`. Both check the release's signature before installing anything.
- **Says which computer is sharing and which is viewing**, with an arrow from one to the other. If both computers have the same name, Annex asks you to rename this one.

### Changed

- **Updates offer the newest version straight away**, not each version in between, and check again when you click Install.
- **Annex always keeps a log** (`annex.log`, Settings → Developer → Log file). It stays on your computer; Annex never sends it anywhere. If something goes wrong, attach it to a bug report. It holds about 10 MB at most.
- **Settings: the five that matter are on top**, with everything else under Advanced. Codes no longer need the Internet switch turned on first.
- **Mac: full screen opens and closes at once**, on the current Space. Disconnecting from full screen takes about 90 ms instead of 650 ms.
- **The menu bar and tray menus hide Nearby during a session.**
- A pointing hand over everything clickable, on Mac and Windows.

### Fixed

- **Mac: the shared picture is no longer washed out** on the viewer. Dark greys were about 14 % too light.
- **Stopping sharing and disconnecting no longer freeze the app** for up to half a second.
- **Mac Extend** no longer briefly captures a display that doesn't exist. Sessions over peer-to-peer Wi-Fi now say so.
- **Running the command-line tool no longer breaks the app's connections.** It keeps its own key, and the app repairs a certificate that doesn't match its key.
