## Annex 0.4.0-pre.1

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. **Install it on both computers.**

### Fixed

- **A Mac's screen shows up on Windows PCs that can't decode HEVC.** Some PCs list an HEVC decoder that then won't start, so a Mac sending HEVC left them with no picture. Annex now checks that the decoder really starts before asking for HEVC; otherwise the picture comes as H.264.
- **The notch drop on a Mac stops offering a computer that's gone.** After you turned sharing off, dragging a file still opened the drop area for the computer that had been connected.
- **What's new on Windows scrolls** instead of growing taller than the screen.
- **The computer names on the Windows live card are clean capsules,** like on the Mac, instead of a smudged grey oval.
