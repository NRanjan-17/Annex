## Annex 0.2.0

Thanks to [@SkidGod4444](https://github.com/SkidGod4444) for most of this release. **Install it on both computers.**

### New

- **Share and connect over the internet with a code.** No VPN, no router settings. Turn on **Settings → Internet** on both computers, then on the sharing one go to **This Mac** or **This PC → Over the internet → Get a code**. On the other, choose **Connect by Code or Address** and type it. A code works once, for 10 minutes; the first time, you also type the PIN.
  - The screen goes straight between the two computers, encrypted. Annex's server (`connect.getannex.dev`) only swaps their addresses. Some strict networks block direct connections: there, add your own relay (a TURN server) in Settings → Internet.
  - Off by default. On your own network, Annex never contacts the server.
- **Nearby lists computers on your private network.** With a mesh VPN such as Tailscale, Headscale or NetBird, computers on the same private network show up in Nearby as **Private network** and connect like any other.
- **Redesigned Mac and Windows apps.** Three places: **Nearby**, **This Mac / This PC** and **Paired Devices**. Nearby shows how each computer is reached and connects with a double-click. The Mac menu bar popover and the Windows tray menu have one sharing switch, the live session, and every nearby computer.
- **Mac ↔ Mac with no router**, over peer-to-peer Wi-Fi (the link AirDrop uses). Can be turned off in Settings → Sharing.
- **In Extend, the pointer can leave the extended screen**, like a real monitor, in every direction between Mac and Windows. Press **⌃⌥⇧Q** (Mac) or **Ctrl+Alt+Shift+Q** (Windows) to leave.
- **Mac: Extended display scaling** in Settings → Sharing, from Sharpest to 200 %.
- **Menu bar and tray icons show state:** faded when sharing is off, solid when on, a green dot during a session.

### Changed

- **Direct Wi-Fi uses your PC's own Mobile hotspot**, as set up in Windows Settings, and never changes it.
- **Mac: the viewer's title bar sits above the picture**, so the other screen's top edge stays visible.

### Fixed

- **Mac Extend: no more black screen** when the encoder gave no frames, and Extend works again after choosing Mirror in System Settings.
- **Connecting over a cable or IPv6** works again.
- **Updates:** a pre-release installed by hand is no longer offered an older stable version.
- Many smaller fixes to layout, spinners and buttons on both apps.

With a VPN on Windows: if Nearby doesn't show the other computer, set the VPN's network to **Private** in Windows Settings ([docs/REMOTE.md](https://github.com/NRanjan-17/Annex/blob/main/docs/REMOTE.md)).
