## Annex 0.1.9

Thanks to [Saidev Dhal](https://saidev.codes) for this release's fixes.

### Fixed

- **Mac: Extend could end with "sent no picture" on a still screen.** When nothing on the Annex Display moved, its only frame could be lost and the session ended. It now keeps that frame.
- **Mac: sharing could keep capturing after it stopped**, if it was stopped while still starting. A lost keyframe is also retried, so the picture recovers sooner.
- **Windows: Extend onto a 4.5K or 5K screen restarted every quarter of a second.** It now starts once.
- **Windows: ending an Extend session while it was still starting** could leave the Annex display behind. It is now removed.
- **Windows: stopping sharing could hang** with the hardware encoder.
- **Windows: the PIN prompt could crash** when another dialog was open, and starting direct Wi-Fi twice at once could leave your own hotspot settings changed.
- **Windows: the Extend display driver** is now found on Windows in any language.
- **Smoother over a poor network:** a frame lost completely now asks for a fresh picture and lowers the quality straight away, and one brief fast moment no longer holds the quality at its lowest.
- **Pairing:** every failed attempt now counts towards the 10-minute pause, not just wrong PINs.
- **Updates:** Annex only installs a file whose name matches the release's version, so an old signed version can't be passed off as a new one.
- **Nearby:** computers found over IPv6 link-local addresses can now be reached.
