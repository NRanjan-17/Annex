## Annex 0.3.3

**Install it on every computer you use with Annex.** The new sound and microphone switches are on the computer being viewed, so that computer needs 0.3.3.

### New

- **Sound and microphone switches for each device.** Under "Can use this computer's mouse and keyboard", each paired device now has **Can hear this computer's sound** and **Its microphone plays here**. Both start on; turn either off for one device without changing your Sound settings. Find them on the Devices page and on the device's card in Nearby.
- **Annex for Linux has a full command line.** Control Annex from a terminal or over SSH, which suits a computer with no screen such as a Raspberry Pi:
  - `annex status`, `annex share on|off`, `annex start --headless --share`, `annex quit`
  - `annex settings`, `annex get <setting>`, `annex set <setting> <value>` for every setting
  - `annex devices` with `allow-control`, `allow-sound`, `allow-mic` and `forget`
  - `annex nearby`, `annex connect`, `annex disconnect`, `annex code`, `annex pin`
  - `annex send`, `annex transfers`, `annex pause|resume|unsend`, `annex update check`, `annex logs`

  Add `--json` for scripts. `annex help` lists everything.

### Fixed

- **Mac: computers on your Tailscale network show in Nearby again.** Opened as an app, Annex couldn't read Tailscale's list of computers, so Nearby only showed computers on the same Wi-Fi.
- **The log now says why Nearby is missing a computer on a private network**: how many computers Tailscale listed, how many answered, and why Tailscale couldn't be asked.
