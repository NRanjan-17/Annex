## Annex 0.1.1 pre-release 2

A test build. Install it by hand once; from here on Annex can update itself.

### New

- **Updates inside Annex.** Settings → General → Updates. Annex checks GitHub at launch and once a day, and offers to install a new version. **Beta updates** gets pre-releases early; turn it off to go back to the latest normal release. *Check for updates automatically* can be turned off.
- **Signed updates.** Each release's checksums are signed when it's built, and Annex installs an update only if that signature and the download's checksum match. A modified download is never installed.

### Notes

- On a Mac, macOS asks for Screen Recording again after each update, because this build isn't notarized yet.
- On Windows, updating closes Annex and opens it again when Setup is done. If Annex was installed for all users, Windows asks for permission first.

Also includes everything in 0.1.1 pre-release 1.
