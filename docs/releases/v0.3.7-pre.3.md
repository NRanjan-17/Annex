## Annex 0.3.7-pre.3

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. **Install it on both computers.**

### Improved

- **More direct connections with a code.** Some internet providers forget an idle connection after a minute, so a code that waited a while before the other computer typed it ended up on the relay. While a code waits, Annex now keeps the way in open, so the two computers can still connect directly.
- **See how many relay sessions are left.** While a session goes through Annex's relay, the sharing page shows how many of today's 10 are left. When they're used up, it says so: they come back at midnight UTC, or you can add your own relay and server in **Settings → Advanced → Internet**, which have no limit.
