## Annex 0.3.5

### Fixed

- **Linux on GNOME: the desktop no longer freezes at login.** On some graphics drivers, Annex starting at the same moment as GNOME froze the whole desktop. Annex now starts 15 seconds after login, and earlier installs switch over the next time Annex opens.
- **Linux on GNOME: a headless computer stays shareable.** With *No one at this screen* on, GNOME locked the idle screen after a few minutes, and the next viewer got no picture. While sharing this way, Annex now keeps the screen from locking. If GNOME closes the screen share anyway, the next viewer gets a new one. A locked screen now says how to unlock it over SSH (`loginctl unlock-session`).
- **Mac: Reverse Mouse Wheel only reverses a mouse wheel.** When you view Windows or Linux, trackpad and Magic Mouse scrolling stays natural.
- **Linux: switches look right on every theme.** Themes like Mint-Y showed a checkbox square instead of the knob. Annex now draws its own switches.
- **Linux: Annex's icon shows everywhere.** It now appears in menus that read it early, like Cinnamon's, and in the taskbar and window switcher.
