## Annex 0.3.7-pre.4

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. **Install it on both computers.**

### Fixed

- **The picture no longer freezes while the pointer keeps moving.** When part of the picture was lost on the way, the viewer asked the other computer for a fresh one only once, and if that was lost too the picture stayed stuck for up to 30 seconds. The viewer now holds the last good picture and keeps asking until a fresh one arrives, usually within a second.
