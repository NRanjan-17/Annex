## Annex 0.1.5

### New

- **Clearer layout.** Settings has General, Sharing, Viewing and Developer; on a Mac, ⌘, opens it. Paired devices and About have their own pages.
- **About and updates.** About shows the app, its version and links, with all update controls underneath: automatic checks, beta updates, the current status, Check now, and when Annex last checked.
- **Less technical clutter.** Identity codes, addresses, stream sizes and latency figures are hidden. Turn on **Settings → Developer → Show technical details** to see them. The log file switch moved to Developer too.
- **A new app icon:** two screens in white on black.
- **Windows: a two-tone sidebar** that folds to icons with the menu button, like Windows Settings.
- **"Extend display".** The option to use this computer as a second screen is now called Extend display everywhere.

### Fixed

- **Windows: no more crash when clicking while controlling the other computer.** Clicking in the viewer window while using your mouse and keyboard on the other computer could close Annex.
- **Windows: one "Connected now" list** on the Share page, with *Switch to direct Wi-Fi* for each viewer.
