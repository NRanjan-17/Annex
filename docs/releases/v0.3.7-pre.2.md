## Annex 0.3.7-pre.2

A pre-release for testing: turn on **Beta updates** (About → Updates) to get it. **Install it on both computers.** Thanks to [Saidev Dhal](https://saidev.codes) for testing over the internet.

### Improved

- **A sharper picture over the internet.** Annex used to lower the picture's quality every time a single frame got lost on the way, and was slow to raise it again, so a good internet connection could look blurry. It now ignores the odd lost frame, lowers the quality only when the connection really can't keep up, and climbs back faster.
- **Fewer blocky moments.** Each frame carries more repair data, so a short burst of lost packets no longer spoils it.
- **HEVC on every platform.** When both computers support it, the picture is sent as HEVC: sharper at the same speed. Otherwise it's H.264, as before, with nothing to set up.
  - **Mac:** every Apple silicon Mac, and Intel Macs that decode HEVC in hardware.
  - **Windows:** sending needs a graphics card with an HEVC encoder (NVIDIA, Intel or AMD); receiving needs Windows' HEVC decoder (the HEVC Video Extensions, built into many PCs and available from the Microsoft Store).
  - **Linux:** sending needs an HEVC encoder on the graphics chip (Intel and AMD through VA-API, NVIDIA); receiving needs a GStreamer HEVC decoder (gstreamer1.0-libav has one).
  - When several computers watch one screen, it's HEVC only while all of them support it.
  - Turn it off in **Settings → HEVC** if the picture misbehaves.
- **The relay is only a fallback, and no longer a lesser one.** Annex uses it only when the two networks block a direct connection. A relayed session now has the same quality as a direct one and no 20-minute limit. Each computer can use it for 10 sessions a day. It stays end to end encrypted.
- **The sharing page shows "Relay"** next to a viewer connected through the relay.
