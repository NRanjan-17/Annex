## Annex 0.1.3

### Fixed

- **Sharing from a Mac works from the start.** macOS now asks for Local Network access as soon as Annex opens. Before, it only asked once the Mac had connected to another computer, so another computer couldn't connect to the Mac until then.
- **Faster connections.** Annex no longer announces addresses that only mean something on the computer itself, so the other computer doesn't waste connection attempts on them.

On a Mac, check that Annex is allowed in **System Settings → Privacy & Security → Local Network**.
